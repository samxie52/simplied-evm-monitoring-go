# Step 3.2: 前端界面开发实现

## 概述
成功为以太坊监控系统创建了现代化的 Web 前端界面，提供直观的数据可视化和管理功能。

## 技术栈

### 核心框架
- **React 19.1.1**: 现代化前端框架
- **Vite 7.1.0**: 快速构建工具
- **React Router DOM**: 单页应用路由管理

### UI 组件库
- **Ant Design 5.26.7**: 企业级 UI 组件库
- **@ant-design/icons**: 图标库
- **antd/locale/zh_CN**: 中文国际化

### 数据可视化
- **Recharts 3.1.2**: React 图表库
- **LineChart, PieChart**: 趋势图和饼图

### 工具库
- **Axios 1.11.0**: HTTP 客户端
- **Day.js 1.11.13**: 时间处理库

## 功能实现

### 1. 仪表板页面 (Dashboard)
- **系统概览**: 总告警数、已处理、待处理、失败数量统计
- **性能指标**: CPU/内存使用率、活跃规则数、平均响应时间
- **数据可视化**: 24小时告警趋势图、严重程度分布饼图
- **最近告警**: 实时显示最新告警信息
- **自动刷新**: 5-15秒间隔自动更新数据

### 2. 告警管理页面 (Alerts)
- **告警列表**: 分页显示所有告警记录
- **高级筛选**: 按严重程度、类型、时间范围筛选
- **搜索功能**: 支持关键词搜索
- **告警详情**: 模态框显示完整告警信息
- **数据导出**: 支持复制交易哈希和地址

### 3. 规则配置页面 (Rules)
- **规则管理**: CRUD 操作管理告警规则
- **规则编辑**: 表单化配置规则参数
- **状态控制**: 一键启用/禁用规则
- **参数配置**: 阈值、时间窗口、冷却时间设置
- **实时验证**: 表单验证和错误提示

### 4. 系统监控页面 (Monitoring)
- **系统状态**: 实时显示系统健康状态
- **性能监控**: CPU、内存、连接数等指标
- **服务状态**: 各个服务组件状态监控
- **性能趋势**: 历史性能数据图表
- **详细指标**: 请求统计、错误率等

## API 集成

### HTTP 客户端配置
```javascript
const api = axios.create({
  baseURL: 'http://localhost:8080',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});
```

### 集成的 API 端点
- `GET /health` - 系统健康检查
- `GET /api/v1/alerts` - 获取告警列表
- `GET /api/v1/alerts/:id` - 获取告警详情
- `GET /api/v1/alerts/stats` - 获取告警统计
- `GET /api/v1/monitoring/status` - 系统状态
- `GET /api/v1/monitoring/metrics` - 性能指标
- `GET /api/v1/monitoring/rules` - 规则列表
- `POST /api/v1/monitoring/rules` - 创建规则
- `PUT /api/v1/monitoring/rules/:id` - 更新规则
- `DELETE /api/v1/monitoring/rules/:id` - 删除规则

## 自定义 Hooks

### useApi Hook
```javascript
const { data, loading, error, execute, refetch } = useApi(
  apiService.getAlerts,
  [],
  { immediate: true }
);
```

### usePolling Hook
```javascript
const { data, loading, isPolling, startPolling, stopPolling } = usePolling(
  apiService.getSystemMetrics,
  5000 // 5秒刷新间隔
);
```

### usePagination Hook
```javascript
const {
  data,
  loading,
  pagination,
  handlePageChange,
  handleFilterChange,
  refresh,
} = usePagination(apiService.getAlerts);
```
